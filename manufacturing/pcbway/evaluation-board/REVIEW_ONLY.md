# DRAFT - review only

This package has not been released for manufacturing.
`reports/export-check.json` checks exported file completeness and consistency; it does not close a release gate.
Review the project's current `reports/validation-register.md` and `reports/release-readiness.md` before
ordering a prototype: a prototype needs the PROTOTYPE_CANDIDATE level (complete CAD, current evidence and
the recorded human reviews). A production release additionally needs the Gate G bench results from an
assembled prototype and a signed approval. This tool does not place manufacturing orders.
